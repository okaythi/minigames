# Workspace Rules & Instructions

## File Length & Modularisation Guideline
- If a file generated by you is ever over 300 lines, THAT IS OK!
- Steps to take in that case:
  1. Re-read the file.
  2. In your internal thought, ask yourself: *"Does this need to be modularised now?"*
  3. If you think so, modularise it.
  4. If not, proceed naturally.
  5. Just let the user know at the end of the job!

## Tool Usage Directive
- Prefer native tools (view_file, replace_file_content, write_to_file, etc.) over shell commands whenever possible.
